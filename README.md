# Gift Yalla

Same-day gifting store for Shopify. *Yalla, make their day.*

| Folder | What it is |
|---|---|
| `giftyalla-storefront/` | Fast headless storefront (Next.js 16 + Shopify Storefront API). The one to launch with. |
| `shopify-theme/` | Regular Shopify Online Store 2.0 theme. Backup / no-hosting option. Includes `seed/` dummy products + collections script. |

## Preview the Next.js storefront (demo mode, no Shopify keys needed)

```bash
cd giftyalla-storefront
npm install
npm run dev
```

Open http://localhost:3000. See each folder's README for connecting Shopify.
